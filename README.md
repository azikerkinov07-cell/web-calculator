# Web Calculator

A simple calculator built with HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Keyboard support (Enter)
- Light/Dark theme

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

```
calculator/
├── index.html
├── style.css
├── calculate.js
├── keyboard.js
├── theme.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
